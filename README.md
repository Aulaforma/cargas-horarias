# SimoHora 20.903/21.625 - Planificador y Simulador de Cargas Horarias Docentes

[![Chile Ley 20.903](https://img.shields.io/badge/Ley-20.903%20%2F%2021.625-blue)](https://www.bcn.cl/leychile)
[![Versión](https://img.shields.io/badge/Versi%C3%B3n-v5.3-00C49F)](#)

SimoHora es una aplicación web interactiva diseñada para la planificación, simulación y optimización de cargas horarias docentes en Chile bajo la **Ley 20.903 (Carrera Docente)** y la **Ley 21.625 (60/40 para 1° a 4° básico en colegios prioritarios >80% SEP)**.

## 🚀 Características Principales

- **Simulación Individual de Cargas Horarias:** Cálculo automático de horas lectivas, no lectivas, recreos proporcionales y permanencia real.
- **Validación Normativa Automatizada:** Semáforos de cumplimiento legal (Verde, Amarillo, Rojo) para evitar infracciones laborales o de la Superintendencia de Educación.
- **Gráfico Interactivo de Carga Apilada:** Desglose porcentual visual del uso del contrato docente.
- **Consolidado de Planta Docente:** Gestión unificada con filtros por estado de cumplimiento y exportación directa a **CSV / Excel**.
- **Configuración de Horario del Colegio:** Definición de jornada semanal, permanencia obligatoria y descansos/colación.
- **Soporte de Contratos Mixtos (Aula + Administración):** Cálculo secuencial de 3 pasos que aparta horas fijas administrativas antes de aplicar la regla 65/35, protegiendo al 100% el 35% no lectivo por ley.
- **Soporte Tema Claro/Oscuro:** Interfaz moderna en Tailwind CSS con lucide icons y diseño responsivo.
